# Native visual QA — 2026-09-30

This pass ran the actual debug ShellDeck binary on a private Xvfb X11 display,
with a temporary XDG profile, a private D-Bus session and the repository's
`manage_stub.py` on loopback. Windows were tested at 1200 × 850 and 820 × 600;
Light and Tokyo Night were both exercised. The fixture account is fictional.
Local terminal/script operations were real; Manage data came from the fixture.
The real SSH config was imported read-only, but no imported host was connected.

Four independent terminal protocol regressions were reproduced with failing
parser tests before fixing them: malformed Unicode OSC palette values could
panic; RIS lost the PTY response channel; RIS reset the shell-completion
sequence; combining accents at the right margin attached to the previous cell.
SDTEST-1926..1929 cover recovery and subsequent observable behavior.

## Automated validation and remaining gaps

`cargo test --workspace --no-fail-fast` passes 852 unique tests: app 100,
core 403, SSH 46, terminal 88, UI 202, update 13. Six live/infrastructure tests
and two documentation examples remain ignored. `cargo clippy --workspace
--no-deps -- -D warnings`, formatting, Linux debug build and whitespace checks
pass. Vendored dependency dead-code warnings are unchanged.

SDTEST-1930..1932 remain **Red / P1** for automated native focus/layout/contrast
coverage; passing screenshots are not presented as an automated harness.
Production authentication/OIDC/keychain, SSH/SFTP/tunnels, actual cloud writes,
AI/provider execution, update installation, tray/desktop companion and native
macOS/Windows interaction still need dedicated live environments. Cross-platform
CI covers the existing native core/update and authority-boundary tests.

Representative original screenshots are committed above. The larger local
capture set, including intermediate states, remains under
`/tmp/shelldeck-visual-qa/screenshots/`; captures with imported hostnames are
kept local rather than published in this repository.
