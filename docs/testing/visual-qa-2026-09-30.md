# Native visual QA — 2026-09-30

This pass ran the actual debug ShellDeck binary on a private Xvfb X11 display,
with a temporary XDG profile, a private D-Bus session and the repository's
`manage_stub.py` on loopback. Windows were tested at 1200 × 850 and 820 × 600;
Light and Tokyo Night were both exercised. Secret-field Settings also passed
at 580 × 600, including scrolling to its action buttons. The fixture account is fictional.
Local terminal/script operations were real; Manage data came from the fixture.
The real SSH config was imported read-only. An initial filtered-picker failure
selected the first imported host and attempted DNS lookup, which failed before
an SSH transport was established. That defect was fixed, and saved connection
UUIDs were explicitly checked before subsequent tunnel starts. All established
SSH sessions and successful tunnel traffic used the disposable loopback fixture.

## Automated validation and remaining gaps

`cargo test --workspace --no-fail-fast` passes 853 unique tests: app 100,
core 403, SSH 46, terminal 88, UI 203, update 13. Six live/infrastructure tests
and two documentation examples remain ignored. `cargo clippy --workspace
--no-deps -- -D warnings`, formatting, Linux debug build and whitespace checks
pass. Vendored dependency dead-code warnings are unchanged.

SDTEST-1930..1934 remain **Red** for automated native focus/layout/contrast and popup event-order and secret-input
coverage; passing screenshots are not presented as an automated harness.
Production authentication/OIDC/keychain, production SSH/SFTP and remote/SOCKS
forwarding, actual cloud writes,
AI/provider execution, update installation, tray/desktop companion and native
macOS/Windows interaction still need dedicated live environments. Cross-platform
CI covers the existing native core/update and authority-boundary tests.

A repeated full suite also exposed a pre-existing flaky SSH-helper test:
two successful helper journeys changed the test process cwd concurrently.
Those journeys now run in isolated child test processes; SDTEST-1788/1789 retain
their original authority assertions. The full suite passes with normal parallel
test execution after this change.

Representative original screenshots are committed above. The larger local
capture set, including intermediate states, remains under
`/tmp/shelldeck-visual-qa/screenshots/`; captures with imported hostnames are
kept local rather than published in this repository.
