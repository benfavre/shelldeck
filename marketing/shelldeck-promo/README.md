# ShellDeck light-mode promo

A 16.8-second, silent ShellDeck marketing example built with Remotion. It uses
real ShellDeck light-mode captures and reusable scene components.

The project also includes a 21.1-second User → Support journey composition,
focused on request creation, support triage, contextual AI and resolution.

```bash
npm install
npm run dev
npm run still
npm run render
npm run still:user-support
npm run render:user-support
```

The rendered files are written to `out/`.
